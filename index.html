Research index · 2025–2026

Decision‑preserving
abstraction

Every project below is a different surface of one question: when is it safe to treat two different things as the same thing? And its mirror: what is the smallest representation that preserves the difference when it matters?

55 entries · 26 repositories · 5 gists · 14 essays · 4 release lines · 26 held private

The program

Suppose a system has states x ∈ X, and its downstream behaviour or decision is represented by F(x). Define an equivalence relation

x1 ∼F x2  ⇔  F(x1) = F(x2)

Then the system can operate on equivalence classes

X / ∼F

instead of retaining every original state. For a single fixed decision this is straightforward. The research challenge is making it work when decisions depend on future trajectories, constraints, costs and changing environments — which is to say, when the equivalence has to be justified rather than assumed.

How can we construct minimal, efficient representations that preserve all decision-relevant information under specified constraints?

This is sufficient statistics, state abstraction, bisimulation, automata minimisation and information theory, treated as one subject rather than five. The projects below explore both sides of it.

Merge when it is safe

FUTCache does not need to remember every state it has visited; it needs a compact representation that preserves what matters about explored geometry.

Refuse to merge

Phantom Clock: two rays can occupy the same spatial position and still differ in direction and arrival time. A memory that treats them as identical manufactures timing errors.

Define legitimacy

Behavioral Quotients asks when two different computational histories may be treated as equivalent at all.

Route on what remains

Model routing: two prompts may look similar yet require different models, and two very different prompts may be served equally well by the same cheap one. The capability required matters, not superficial similarity.

Guard the distinctions

Authorization Lattice and Agent Guardrail: two agents may request the same action while holding different permissions. Ignoring that distinction is a security failure.

Repositories

26 entries

Twenty-six new repositories since October 2025, plus six continuing. Each is a different surface of the same question.

01
phantom-clock ↗ HTML · ★ 0 · 2026-10-22

Optical phase space becomes a memory medium. Two rays can share a position and still differ in direction and timing, so collapsing them manufactures errors. This essay keeps phase as a first-class coordinate and documents the ellipsoid inside the clock.

02
eigen-attention ↗ JavaScript · ★ 0 · 2026-10-18

Attention reframed as constrained spectral regression: tokens are eigenvectors under a task-induced operator, and the softmax is solved for rather than assumed. The repository extends the theorem, adds controlled experiments, and ships reproducible checks that show where the approximation holds.

03
persistent-discovery-index ↗ Python · v0.5.0 · 2026-09-15

A microscope for agent behaviour. PDI reads pi, OpenAI, LangSmith and canonical traces to locate the exact boundary where useful discovery ends and wasteful exploration begins, and report that boundary at behavioural resolution instead of returning one blunt aggregate score.

04
behavioral-quotients ↗ HTML · ★ 1 · 2026-09-12

Two computational histories may be equivalent when they produce the same relevant behaviour. This paper states the equivalence relation explicitly, derives which observations must be retained for it to hold, and presents the quotient as a design principle for computation.

05
agent-guardrail ↗ Python · ★ 1 · 2026-08-31

Policy enforcement and permission testing for AI agents. Mock enterprise APIs simulate synthetic user consent, and requests are blocked before deployment when an agent's authority is not actually established, so abstraction never erases the security-relevant distinctions between any two callers.

06
FUTCache ↗ C · ★ 2 · 2026-08-23

A bounded-memory sufficient-state representation of explored geometry. FUTCache merges visited states whenever merging loses nothing a later decision needs, scaling to a million production traces while the cache itself stays fixed in size, and released three times in summer 2026.

07
novelty-geometry ↗ HTML · ★ 2 · 2026-08-20

Traversal, ordered novelty, memory and asymptotic completion in metric and hyperbolic spaces. The framework formalizes which directions an agent has genuinely covered, separating reached territory from a reworded revisit of ground explored, and shows how completion behaves as space grows.

08
tensor-to-tenant ↗ Python · ★ 2 · 2026-08-04

A hundred-and-eight-week apprenticeship in AI systems engineering, spanning mathematics, ML systems, LLMs, distributed systems and design. Built as a static site with deploy automation, analytics integration, pacing budgets and a GPU redirect ladder, and published weekly for two full years.

09
reify ↗ D · ★ 0 · 2026-07-27

A declarative SDK and compiler for constraint optimization and decision-intelligence engines. Constraints are declared rather than hand-encoded, and the compiler decides how much structure can be discarded while every remaining degree of freedom still changes the decision that comes out.

10
docs ↗ CSS · ★ 1 · 2026-07-20

The ShunyaBar Labs blog: a publishing surface for essays, papers and notes. Deliberately quiet, so that the writing carries the argument while the site stays out of the reader's way, with light and dark themes that follow the system setting.

11
NoetherLeap ↗ HTML · v1.0 · 2026-06-30 private

Constraint-aware optimization that pairs physics-informed neural networks with Bayesian search and symmetry discovery. The system exploits conserved quantities to avoid searching dimensions that provably cannot change the outcome, and reports the symmetries it found in advance rather than assuming them.

12
miwa-discord-bot ↗ HTML · 2026-06-22 private

A Discord bot deployed as a static front end, keeping its state server-side and out of the browser. Conversations are summarised for retrieval without losing the distinctions a later reply has to respect, and the user interface stays deliberately plain.

13
axiom-synergy ↗ ★ 0 · 2026-06-18 private

A framework measuring how rules, constraints and logic interact. Cooperative game theory assigns each rule a marginal contribution, and the framework reports hidden synergy when constraints reinforce one another, and conflict when they collide, where the design error usually sits.

14
authorization-lattice ↗ HTML · 2026-06-04 private

Two agents may request the same action while holding entirely different permissions. Ignoring that distinction produces a security failure, so the work orders authority in a lattice and still keeps ownership attached to objects that may have none at all.

15
factor-agent ↗ HTML · ★ 1 · 2026-05-20

Invariant-preserving agent harnesses built on OTP supervision, arithmetic security lattices and lawful composition. The harness watches that an agent preserves the quantities it was supposed to preserve exactly, and reports every violation rather than silently averaging it out of sight.

16

17

Primes act as thermodynamic fuel, the Riemann zeta function serves as infinite memory, and arithmetic turns out to be a very complex piece of origami. The essay reads number theory as an energy landscape with conserved quantities and irreversible flows.
